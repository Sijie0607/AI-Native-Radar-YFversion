# AI-Native 读书雷达 - 首页设计方案

## 1. 首页设计目标与范围边界

### 设计目标
让用户进入页面后，在 10 秒内理解：
1. 这个产品是一个 AI 从业者的读书雷达
2. 雷达上的每个点代表一本书
3. 八大方向代表不同 AI 学习/实践领域
4. 内外圈代表不同阅读难度或进阶阶段
5. 推荐指数和推荐理由帮助用户判断是否值得读

### 范围边界
- **包含内容**：雷达图展示、8 个领域书名框环绕、书籍详情侧栏、筛选面板、导航入口、**书籍推荐抽屉**、**评分投票抽屉**、**历史版本对比（本周更新）**
- **不包含内容**：用户体系 / 账号、审核后台、复杂评分加权算法、AI 自动审核（周更定时触发）
- **说明**：早期 spec 将「完整推荐提交页面、复杂评分机制、历史版本对比、完整书单列表页」列入不包含范围；当前原型均已实现（推荐/评分以右侧抽屉落地、版本对比以「本周更新」入口落地、书单列表页为 `/list` 路由）。

---

## 2. 首页信息架构

首页由以下区域组成：
1. **顶部导航区**：品牌标识、导航入口（书单列表 / 雷达图 / 书籍推荐按钮）
2. **页头区**：标题、简介、图例说明、「本周更新」版本对比入口
3. **主视觉区**：雷达图为主体，8 个领域书名框环绕（窄屏降级为两行四列网格）
4. **筛选区**：左侧可折叠筛选面板（领域 / 难度 / 推荐指数滑杆 / 搜索）
5. **浮层区**：详情侧栏、推荐抽屉、评分抽屉、版本对比浮层面板
6. **入口区**：书单列表页入口（`/list` 完整列表页，非仅入口）

### 布局分区说明
- **首屏**：导航区 + 页头（标题/图例/本周更新）+ 左侧筛选面板 + 右侧雷达主体

- **书名框环绕**：8 个领域卡贴靠各自对应扇形方位（上/右上/右/右下/下/左下/左/左上）；左右窄框宽 18%、四角框宽 24%、上下框宽 36%
- **窄屏**：筛选面板收起为一行按钮，书名框降级为雷达下方两行四列网格，与雷达零重叠

## 5. 核心用户任务流

### 任务流一：从雷达图探索
用户进入 → 查看雷达图 → 悬停查看书籍摘要 → 点击查看详情 → 关闭详情 → 继续探索

### 任务流二：从筛选探索
用户进入 → 使用筛选器 → 查看筛选后的雷达图 → 悬停查看摘要 → 点击查看详情 → 关闭详情

### 任务流三：从入口跳转 / 共建
- 用户进入 → 点击导航「书籍推荐」→ 打开推荐抽屉 → 填写提交 → 查看结果/记录 → 返回浏览
- 用户进入 → 查看详情侧栏 → 评分投票 → 提交半星评分 → 推荐指数实时更新 → 返回浏览
- 用户进入 → 点击「本周更新」→ 雷达进入版本对比态 → 查看新增/指数升降 → 关闭对比

### 任务流四：从列表页筛选
用户进入书单列表页 → 筛选/搜索 → 浏览卡片 → 点击评分入口或进入详情

## 6. 关键交互设计

### 悬停交互（Hover）
- **雷达图点**：悬停放大1.5倍，显示摘要卡片
- **摘要卡片内容**：书名、作者、推荐指数、推荐理由摘要
- **卡片位置**：跟随鼠标，避免超出视口

### 点击交互（Click）
- **雷达图点 / 书名框**：打开书籍详情侧栏
- **导航链接**：跳转到对应页面
- **筛选选项**：切换选中状态
- **关闭按钮**：关闭详情侧栏 / 抽屉
- **「本周更新」按钮**：进入 / 退出版本对比态

### 筛选交互
- **领域筛选**：多选，实时更新雷达图
- **难度筛选**：多选，实时更新雷达图
- **推荐指数筛选**：滑杆（3.0-5.0，0.5 步长），实时更新
- **筛选清空**：一键重置所有筛选
- **筛选面板折叠**：收起为 `w-16` 图标按钮（带激活筛选角标计数）

### 版本对比交互
- **进入**：点击「本周更新」，diff 拉取一次后本地缓存复用
- **对比态**：新增书高亮、指数升/降叠加 ↑/↓ 徽标；跌出雷达的书不单独标注（面板以全局提示交代成员变动规则）；被筛选隐藏但有变化的书显示离屏迷你标记
- **状态优先级**：selected > hover > 对比态 > 默认
- **退出**：点击「退出对比」或面板关闭按钮
- **无对比可看**：无上一版时提示「暂无上一版本可对比」，加载失败可重试

## 7. 页面状态清单

| 状态名称 | 视觉表现 |
|---------|---------|
| 默认状态 | 完整雷达图、所有合格书籍点可见（默认 `minScore=3`）、无筛选、无详情 |
| 加载状态 | 雷达图区加载提示；数据拉取中 |
| Hover状态 | 雷达图点放大、显示摘要 tooltip；对应书名框高亮 |
| 选中状态 | 详情侧栏打开、选中的点高亮 |
| 筛选状态 | 只有符合条件的点可见、筛选器显示当前选择 |
| 空结果状态 | 领域书名框显示「暂无符合条件的书籍」 |
| 错误状态 | 数据加载失败提示（详情见页面实现） |
| 对比态 | 版本对比面板展示计数；新增/指数升降书叠加徽标；跌出雷达的书不单独标注 |
| 抽屉态 | 推荐 / 评分抽屉或详情侧栏打开，覆盖在雷达之上 |

## 8. 状态流转说明

```
默认 → 加载 → 默认
↓
Hover → 默认
↓
Click → 选中 → 默认
↓
筛选 → 筛选状态 → 清空 → 默认
↓
筛选无结果 → 空结果 → 清空 → 默认
↓
出错 → 错误 → 重试 → 默认
↓
本周更新 → 对比态 → 退出 → 默认
↓
评分/推荐 → 抽屉态 → 关闭 → 返回原浏览位置
```

### 详细状态触发
- **加载状态**：页面初始化触发，数据加载完成后回到默认
- **Hover状态**：鼠标悬停在雷达图点/书名框上触发，鼠标离开后回到默认
- **选中状态**：点击雷达图点触发，关闭详情侧栏后回到默认
- **筛选状态**：点击筛选选项触发，点击清空后回到默认
- **空结果状态**：筛选无结果触发，点击清空后回到默认
- **错误状态**：数据加载失败触发，点击重试后回到加载状态
- **对比态**：点击「本周更新」触发（有上一版快照时），退出后回到默认；无上一版则提示「暂无上一版本可对比」
- **抽屉态**：点击推荐 / 评分 / 详情侧栏入口触发，关闭后至少保留原筛选条件

## 9. 数据与内容字段需求

### 书籍数据字段（对齐 `src/types` 的 `Book`）
| 字段名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| id | String | 是 | 书籍唯一标识（如 `imported-1`） |
| displayNumber | Number | 是 | 跨领域连续全局编号（逆时针顺序分配） |
| title | String | 是 | 书名（可带【分类】前缀，环绕框可去前缀） |
| subtitle | String | 否 | 副标题 |
| author | String | 是 | 作者 |
| domain | Enum | 是 | 所属领域（8 个领域之一） |
| difficultyLevel | Number | 是 | 难度（`1|2|3`，入门认知/方法实践/深度进阶） |
| sectorIndex | Number | 是 | 雷达扇区索引 0-7（对应领域） |
| ringIndex | Number | 是 | 雷达难度圈索引 0-2 |
| x / y | Number | 是 | 雷达图坐标 |
| recommendationScore | Number | 是 | 推荐指数（3-5，评分提交后按平均分实时更新） |
| reasonShort / reasonFull | String | 是 | 推荐理由摘要 / 完整理由 |
| fitFor / takeaways | Array | 是 | 适合人群 / 核心收获 |
| contentType | String | 是 | 资料类型（书籍） |
| tags | Array | 是 | 标签 |
| votesCount | Number | 是 | 评分人数 |
| recommendationCount / ratingCount | Number | 否 | 推荐次数 / 评分次数 |
| competenceThemes | Array | 否 | 能力主题标签 |
| recommendations | Array | 是 | 推荐理由列表（见下） |
| cover | String | 否 | 封面图片 URL |

### 推荐理由字段
| 字段名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| id | String | 是 | 推荐唯一标识 |
| recommender | String | 是 | 推荐人姓名 |
| isAnonymous | Boolean | 是 | 是否匿名 |
| reason | String | 是 | 推荐理由内容 |
| score | Number | 是 | 推荐评分（3-5） |
| recommendedAt | String | 是 | 推荐时间 |
