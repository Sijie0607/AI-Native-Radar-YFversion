# AI-Native 读书雷达 - UX Design Guideline

## 1. 风格关键词与可执行规则

### 关键词一：专业可信
- **可执行规则**：
  - 优先使用几何化、线条感强的视觉元素，避免曲线过柔或不规则形状
  - 信息层级通过排版和留白区分，而非装饰元素
  - 推荐数据可视化优先采用理性的图表呈现方式
  - 色彩饱和度控制在中等偏低，避免过度鲜艳

### 关键词二：体系清晰
- **可执行规则**：
  - 所有页面采用一致的网格系统
  - 信息分组通过间距而非装饰元素分隔
  - 分类标签始终保持在相同的视觉位置
  - 难度层级通过同心圆或深浅变化体现，确保空间感一致

### 关键词三：Less is More（少即是多）
- **可执行规则**：
  - 每个页面的主视觉焦点不超过1个
  - 辅助信息默认隐藏或弱化，按需显示
  - 去除所有非功能性装饰元素
  - 文案精简，避免冗余

### 关键词四：编辑感
- **可执行规则**：
  - 通过字号对比（3级以上差异）建立清晰层级
  - 标题使用稍粗字重，正文保持中等字重
  - 留白节奏遵循一致的网格倍数
  - 图文混排时保持基线对齐

### 关键词五：纸感（编辑 / 阅读质感）
- **可执行规则**：
  - 背景为米黄纸面色板（`--paper-*` 变量），`slate` 色系经 `.paper-app` 覆写映射到纸面
  - 雷达圆内含 `feTurbulence` grain 纸纹，纸纹只作用于圆内（`clipPath#radar-circle-clip`）
  - 品牌强调使用 `--paper-accent: #0e42d2`（按钮 / 选中态 / 统计数字），但占比克制
  - 采用现代无衬线字体，卡片式布局，使用线性图标
  - 轻微悬浮阴影效果
  - 深度优先时营造「雷达图 + 书本目录」的编辑感，而非冷色调科技感

> 说明：早期版本曾以「深蓝科技感」为关键词五；当前原型整体切换为纸感主题（见 [radar-home-visual-update.md](./radar-home-visual-update.md)）。

## 2. 需规避的倾向及触发原因

| 需规避的倾向 | 具体表现 | 触发这些倾向的设计动作 |
|-------------|---------|----------------------|
| **电商感** | 过度强调促销感、紧迫感 | 使用倒计时标签、「爆款」「热销」文案、过度渐变背景、圆角过大、大面积橙色/红色、购物车/收藏图标过度装饰化 |
| **社区论坛感** | 信息密度过大、评论区视觉占比过高、用户头像喧宾夺主 | 使用多层嵌套回复框、用户头像过大、点赞分享按钮过于显眼、聊天式排版、过度使用emoji |
| **卡通化** | 形象可爱、线条圆润、色彩高饱和 | 使用圆角半径过大（>12px）、过度渐变、矢量插画风格过于Q版、字体过于圆润、过度阴影效果 |
| **炫技式渐变发光** | 装饰性过强、喧宾夺主、影响可读性 | 使用渐变背景铺满整个页面、元素发光效果过强、霓虹色彩、元素悬浮时过度放大变形 |

## 3. 色彩系统

### 主色调（品牌色）
- **强调色**：`--paper-accent: #0e42d2`
- **用途**：关键操作按钮（书籍推荐 / 评分）、筛选激活角标、统计数字、选中态强调
- **设计原则**：强调蓝只作为功能强调色出现，占比克制，不抢纸感底色的主次

### 中性色系统（纸感）
当前原型为纸感主题，`slate` 色系经 `.paper-app` 覆写映射到米黄纸面色板（`src/index.css` 中的 `--paper-*` 变量）：

- **背景层级**：
  - 主背景：`--paper-bg: #e8e2d5`（米黄纸面）
  - 面板背景：`--paper-panel: #f3eddf`
  - 卡片背景：`--paper-card: #ede5d6` / `--paper-card-soft: #f8f2e8`
  - 边框：`--paper-border: rgba(97, 80, 50, 0.28)`
- **文字层级**：
  - 主文字：`--paper-ink: #211b14`
  - 辅助文字：`--paper-muted: #6f6252`
  - 弱化文字：`--paper-faint: #9b8f7f`
  - 强调（文字/选中）：`--paper-accent: #0e42d2`
- **设计原则**：中性纸色占比不低于 80%，强调蓝与领域 token 色合计不超过 20%

### 强调色（功能色）
- **推荐指数**：3-5 星，评分提交后按平均分实时更新（颜色不做星级渐变，用数字与星级表达）
- **状态指示**：加载中、成功、错误使用通用状态色（成功 `#10B981` / 警告 `#F59E0B` / 错误 `#EF4444`）

### 分类色（八大领域）
- 当前八大领域使用 `src/constants/index.ts` 中的 `DOMAIN_COLOR_TOKENS` 作为唯一来源，不再沿用早期低饱和色板。
- 每个领域 token 拆为：`base`、`sector`、`sectorHover`、`tagBg`、`tagBorder`、`text`、`labelMuted`、`dotLight`、`dotDark`。
- **雷达渲染**：大面积扇区使用 `sector` / `sectorHover` 高透明暗色；书籍编号圆点使用 `base + dotLight + dotDark` 的实色木质球状质感；领域标签 / 筛选 chips / 列表标签使用 `tagBg + tagBorder + text`。
- **设计原则**：
  - 同一领域在不同页面使用完全一致的颜色
  - 分类色用于领域识别与分组；大面积背景必须使用高透明 token，不直接使用实色 `base`
  - dot 是雷达主视觉，可以比扇区和标签更实、更清楚

### 版本对比色（`COMPARE_COLORS`，新增）
- 新增 / 指数升：`#3f6b4f`
- 指数降：`#9c5a30`
- 跌出雷达的书：**不渲染残影、不单独标注**（成员按 Top 8 + ≥3.0 每周变动，对比面板以一行全局提示交代）

### 色彩使用场景约束
- **分类场景**：使用 8 个领域 token，区分扇区、tag、文字与 dot
- **强调场景**：使用品牌主色或推荐指数色
- **状态场景**：使用功能状态色
- **背景场景**：只使用中性色系统

## 4. 字体与排版规范

### 字体选择
- **字体家族**：现代无衬线字体
- **字体风格**：几何化现代字体，兼具可读性优先
- **设计原则**：确保跨平台一致性

### 字体层级
| 层级 | 用途 | 字号关系 | 字重 |
|-----|------|---------|------|
| H1 | 页面标题 | 基准字号 × 2.5 | 700 |
| H2 | 区块标题 | 基准字号 × 1.75 | 600 |
| H3 | 子区块标题 | 基准字号 × 1.25 | 600 |
| 正文 | 主要内容 | 基准字号 | 400-500 |
| 辅助 | 说明文字 | 基准字号 × 0.875 | 400 |
| 标签 | 分类标签 | 基准字号 × 0.75 | 500 |

### 行高设置
- 标题：1.2 - 1.3 倍
- 正文：1.5 - 1.6 倍
- 辅助文字：1.4 倍

### 排版规则
- 左对齐为主要对齐方式
- 中英文混排时，字母/数字与汉字之间留1/4空格
- 标题与正文间距至少为1行高
- 段落间距为0.5行高
- 标题加粗

## 5. 间距与网格系统

### 基础网格单位（8px）
- 所有间距都使用 8px 的倍数（8px、16px、24px、32px、48px、64px）

### 页面级网格
- 首页内容区域最大宽度：`max-w-[1440px]`
- 首页雷达舞台最大宽度：`max-w-[1280px]`
- 列表页内容区域最大宽度：`max-w-[1280px]`
- 左右边距：16-24px（移动端自适应）
- 栅格列数：12列
- 列间距：16px

### 组件级间距
- 卡片内边距：24px
- 卡片之间距：16px
- 表单元素间距：16px
- 标签间距：8px

### 留白节奏
- 大区块之间：48px
- 小区块之间：24px
- 元素分组之间：16px
- 相关元素之间：8px

## 6. 通用状态视觉语言

### 默认状态
- 视觉表现：中性色、基础字号、无特殊装饰
- 设计原则：清晰但不抢眼，保持页面整体平衡

### Hover（悬停）状态
- 视觉表现：
  - 可交互元素：轻微上浮（2-4px）、微妙阴影、明度变化
  - 信息元素：不透明度变化、辅助信息淡入
  - 卡片：轻微上浮 + 阴影效果
  - 雷达图点：放大并显示详情卡片
- 动画时长：150-200ms，缓动函数
- 按钮：圆角矩形，轻微悬浮阴影效果

### 选中状态
- 视觉表现：
  - 品牌主色标识、边框、背景
  - 状态指示器（圆点、对勾）
- 设计原则：明确但不突兀，不破坏整体视觉平衡

### 对比态（版本对比）
- 视觉表现：
  - 新增书：正常点位 +「新」徽标（`#3f6b4f`）
  - 指数升：点位上「↑」徽标（`#3f6b4f`）
  - 指数降：点位上「↓」徽标（`#9c5a30`）
  - 跌出雷达的书：不渲染残影、不单独标注（避免被当前点位遮挡；成员变动规则在面板以全局提示交代）；被筛选隐藏但有变化的书渲染为离屏迷你标记
- 状态优先级：`selected > hover > 对比态 > 默认`，即对比态不破坏 hover / 选中
- 动画时长：150-200ms，缓动函数

### 加载状态
- 视觉表现：
  - 骨架屏（与真实内容布局一致）
  - 加载动画简洁（如旋转圆形、进度条）
- 设计原则：不使用过度花哨的动画，避免让用户等待焦虑

### 空态
- 视觉表现：
  - 简洁的图标或插画
  - 清晰的文案说明
  - 引导性操作按钮
- 设计原则：保持与产品调性一致，不使用卡通化插图

### 错误态
- 视觉表现：
  - 使用错误状态色标识
  - 清晰的错误信息文案
  - 提供解决方案或重试按钮
- 设计原则：不责备用户，提供建设性帮助

## 7. 数据可视化通用原则

### 点元素（雷达图资料点）
- **大小**：
  - 当前原型使用 `MIN_BOOK_POINT_RADIUS = 12` / `MAX_BOOK_POINT_RADIUS = 20`（SVG 坐标单位）
  - 推荐指数越高，点越大：3.0 分取最小半径，5.0 分取最大半径，中间按线性比例过渡
  - 设计原则：大小差异要能表达推荐分高低，但不引入球与球之间的粘滞融合
- **颜色**：使用对应领域的分类色
- **边框**：1-2px 白色/浅色边框，增强可读性
- **悬停状态**：放大1.5倍，显示卡片式摘要
- **摘要卡片**：只在 hover 到雷达球形点位时出现，并贴近对应点位；外围书名模块不承担书籍详情说明

### 圈层元素（难度层级）
- **线条样式**：
  - 线条粗细：内圈细、外圈稍粗（1-2px差异）
  - 线条颜色：中性灰，透明度从内向外递增
- **视觉层次**：圈层为辅助信息，不抢点元素的视觉焦点

### 扇区元素（领域分区）
- **填充**：低透明度填充（透明度不超过0.1）
- **边框**：细分隔线使用极细线条
- **标签**：扇区标签放在外部，不占用内部空间

### 视觉层级处理
- **主视觉**：资料点（高对比度、鲜艳度）
- **辅助视觉**：圈层和扇区（低对比度、低鲜艳度）
- **信息呈现**：默认状态弱化辅助信息，悬停时强化相关信息

### 信息密度处理
- 同一区域点过多时，可采用聚类或智能避让
- 优先保证高推荐指数资料的可见性
- 避免点重叠影响可读性

### 雷达图特殊要求（当前原型）
- **画布**：自研 SVG，`viewBox 900×900`，雷达圆 `maxRadius = 280`
- **背景**：米黄纸底（径向渐变）+ `feTurbulence` grain 纸纹，纸纹经 `clipPath#radar-circle-clip` 只作用于圆内
- **支持功能**：悬停放大 + tooltip、点击打开详情侧栏、版本对比层；**不支持缩放和拖拽平移**（早期设计已移除）
- **8 个扇形区域**：使用 `DOMAIN_COLOR_TOKENS` 中的高透明暗色，扇形花瓣按该领域书量缩放半径（书越多扇区越外扩）
- **外围书名模块**：只展示领域标签和书名列表，水平摆放在雷达外圈；使用轻微浮动和阴影，不倾斜、不作为书籍详情卡片
- **难度层级**：3 层虚线难度环（入门认知/方法实践/深度进阶，半径 0.3/0.6/0.9 倍），带慢速旋转动画
- **资料点分布**：领域决定 45° 扇区方向；`difficultyLevel` 决定内/中/外三段半径带（入门 0.18-0.31、方法 0.42-0.58、进阶 0.72-0.90），同层多书通过扇区内角度与半径微分布避免重叠
- **资料点样式**：编号圆点（跨领域连续 `displayNumber`），同一领域颜色一致；dot 使用更实色的木质球状质感，大小由 `recommendationScore` 映射，hover 放大并显示卡片式摘要
- **本轮不做**：不启用 SVG goo / liquid filter，不表达球与球之间的粘滞融合程度
- **中心结构**：中心准星 + 8 条罗盘线 + 固定在雷达圆外圈的领域斜体标签
- **对比层**：新增/升降徽标、离屏迷你标记（详见上文「对比态」）

## 8. 组件复用边界

### 强制全站统一（不可调整）
- 色彩系统（所有颜色定义）
- 网格系统（8px基础单位、12列栅格）
- 字体层级和排版规则
- 通用状态视觉语言（hover/选中/加载/空态/错误态）
- 导航组件样式（顶部固定，品牌名称在左，列表页 / 书籍推荐链接在右，纸面主题 + 品牌蓝强调按钮）
- 按钮组件基础样式（圆角矩形，轻微悬浮阴影效果）
- 图标风格（Lucide React 线性图标）

### 允许页面按需调整
- 页面布局结构（只要符合网格系统）
- 信息密度（在合理范围内）
- 数据可视化具体实现方式（只要符合数据可视化通用原则）
- 页面级动画效果（只要风格一致）
- 特殊页面的品牌色占比（可适度提高但不超过30%）
- 列表页布局（网格布局，卡片悬停有上浮效果）
